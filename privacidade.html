Política de Privacidade

Última atualização: 01 de Janeiro de 2026.

A Agro Intelligence ("Nós") respeita a sua privacidade e está comprometida em proteger os dados pessoais dos usuários da sua Plataforma, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD).

1. Dados Coletados

Para o funcionamento e fornecimento do serviço, coletamos as seguintes informações:

  • Dados de Identificação: Nome do cliente/usuário e número de WhatsApp (utilizado como login único).
  • Dados Agronômicos: Informações de manejo inseridas pelo administrador ou cliente, como código de talhões, variedades, estágio de corte, datas de plantio e produtividade.
  • Dados de Geolocalização: Polígonos (desenhos de áreas de fazendas) enviados via arquivos KML/KMZ.

2. Finalidade do Tratamento

Os dados coletados são utilizados exclusivamente para:

  • Autenticação e controle de acesso dos usuários à Plataforma.
  • Cálculo de áreas agrícolas, processamento de imagens de satélite e geração de mapas NDVI.
  • Cruzamento de dados de manejo para geração de relatórios e indicadores (KPIs).
  • Cumprimento de obrigações contratuais e de cobrança.

3. Compartilhamento de Dados

A Agro Intelligence não vende, aluga nem comercializa os dados dos seus clientes. O compartilhamento ocorre apenas com provedores de infraestrutura essencial para o funcionamento do sistema (ex: provedores de banco de dados em nuvem e APIs meteorológicas), sempre sob estritos acordos de confidencialidade.

4. Segurança dos Dados

Implementamos medidas técnicas e organizacionais de segurança (criptografia, servidores em nuvem certificados e autenticação por senha) para proteger os dados contra acessos não autorizados, perda ou alteração.

5. Direitos do Titular (LGPD)

Como titular dos dados, o usuário possui o direito de solicitar acesso, correção, anonimização ou exclusão de seus dados pessoais, mediante solicicação formal ao nosso canal de suporte.

6. Retenção de Dados

Os dados serão retidos pelo período vigente do contrato de prestação de serviços. Após o término do contrato, mediante solicitação, os dados de geolocalização e manejo podem ser excluídos de nossos bancos de dados.
